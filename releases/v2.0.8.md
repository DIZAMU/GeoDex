# GeoDex 2.0.8

Settings is split into four tabs, Study, Topics, Appearance and Backup, so you no longer scroll one long page. The tab you open stays in the address, so a reload brings you back to it.

Help is now a list of common questions about grading, difficulty, scheduling, new cards, the daily goal, where your progress is kept and keyboard shortcuts. Each opens on its own. Levels and XP stay as they were, and the list of screens is gone.
