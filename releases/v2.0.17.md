# GeoDex 2.0.17

Ready to go public. The site now sends security headers, including a content security policy that allows scripts only from GeoDex itself, so the theme script that runs before the first paint moved into a file of its own. Data files are always served as files of their own, which the policy allows, and the browser tests now run under the same headers as the live site. Restoring a backup checks every answer, hook vote and setting in the file and refuses one that is too large to be a backup. Build tools are updated and CI checks dependencies for known vulnerabilities. The README gains a quick start.
