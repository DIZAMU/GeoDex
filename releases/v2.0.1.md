# GeoDex 2.0.1

New versions now load by themselves. When an update arrives, the app reloads as soon as it is ready, or, if you are in a session or a drill, as soon as you leave it, so no question is cut off and no answer is lost.

Also in this release
- The end-to-end tests run as four shorter jobs, so they finish within the time a job may run
- A test that could open Today before a setting was saved now waits for the save
